# Raytracer (трассировщик лучей)

## Идея проекта

Разработка программы для создания фотореалистичных изображений 3D-сцен методом трассировки лучей. Программа позволяет визуализировать трёхмерные объекты с реалистичным освещением, тенями и материалами, а также рассчитывать параметры освещения в заданных точках сцены.
